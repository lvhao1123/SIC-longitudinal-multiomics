# Reproduction instructions

## Environment

The analyses used R 4.4.2. Relevant recorded versions include survival 3.7-0 and fgsea 1.32.4. Full stage-specific sessions and package versions are in `environment/` and `plotting/environment/`. The root renv lock and stage session records have different coverage; restore dependencies against the actual stage rather than assuming one lock captures all later packages. No script should install dependencies automatically.

## Controlled-input statistical route

Set SIC_PROJECT_DIR to the repository, CMAISE_DATA_DIR to authorised inputs, and SIC_OUTPUT_DIR to a new private output directory outside both. See `config/` and `docs/INPUT_CONTRACT.md` for field and file requirements.

```
Rscript --vanilla analysis/run_authorized.R --preflight-only
```

This validates inputs only. The explicit `--run-historical-pipeline` option runs the historical primary computations in a fresh private directory, not the final presentation tables. Original clinical computations include the historical 41-contrast family. Use `revision/clinical/01_update_clinical_BH40.R` for the exploratory 40-contrast amendment; do not substitute BH41 into the current table/figure route. Revision analyses are listed in CODE_CHAIN.tsv with their own controlled inputs. No single command is claimed to recover unavailable historical annotation provenance.

## Current aggregate table route

```
python analysis/run_current_tables.py NEW_TABLE_OUTPUT
```

The entry computes diagnostics from existing aggregate results and prepares Table 1/S9 displays from one normalised summary. It does not run a statistical test. Assembly checks hashes and writes the declared table blocks. S1 excludes PCT, and S2 uses current BH40 values. Supplementary Tables S1–S18 are supplied for comparison.

## Figure route

See `plotting/README.md` and `plotting/FIGURE_CODE_DATA_INDEX.tsv` for exact commands, part mapping, physical sizes and inputs. Quantitative figures are generated by R from aggregate data. Display reproduction is not independent patient-level statistical reproduction or validation of experimental QC definitions.

## Verification boundaries

Helper/interface tests use synthetic examples and read-only checks. Aggregate-to-table and source-data-to-figure comparisons are separate from statistical replication. Main and sensitivity results retain their own model specifications and multiplicity families. Severe Day-5 protein event limitations, residual selection bias, and uncertainty about the QC input scale/grouping remain relevant even when code executes.

Runtime depends on hardware; no unmeasured end-to-end duration or memory guarantee is provided. See recorded logs and session files for stages that have actually been executed.
